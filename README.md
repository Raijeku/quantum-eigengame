# Quantum EigenGame for Excited States

This repository contains all the source code used to generate results and test presented in "Quantum EigenGame for Excited States".

## Contents

* ``EigenGame.ipynb``: Notebook storing code for experiments on finite-differences EigenGame and parameterized EigenGame.
* ``EigenGame_theory.ipynb``: Code for testing theory from [EigenGame: PCA as a Nash Equilibrium](https://arxiv.org/abs/2010.00554) and this paper numerically.
