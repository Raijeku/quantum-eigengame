# Quantum EigenGame for Excited States

This repository contains all the source code used to generate results and plots presented in "Quantum EigenGame for Excited States".

## Contents

* ``EigenGame_quantum_experiments.ipynb``: Notebook storing code for experiments on the parameterized EigenGame (QuantumGame) vs VQD.
* ``EigenGame_theory.ipynb``: Code for testing theory from [EigenGame: PCA as a Nash Equilibrium](https://arxiv.org/abs/2010.00554) and this paper numerically. This notebook also includes code for our ablation study experiments of the exact EigenGame vs zeroth-order EigenGame.
